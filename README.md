# Deutsch A1 Master — Netzwerk neu A1 (Kapitel 1 – 12)

موقع تعليمي تفاعلي كامل لمذاكرة منهج **Netzwerk neu A1** من الدرس الأول حتى الدرس الثاني عشر (كل درس في صفحة مستقلة) مع النطق الصوتي الألماني، الخرائط الذهنية، بطاقات الحفظ، الاختبارات، والملحق الذهبي لامتحان مستوى A1.

## هيكل الملفات
- `index.html` — الصفحة الرئيسية للموقع
- `css/style.css` — التصميم المتجاوب (الوضع النهاري والليلي + دعم العربية RTL والألمانية LTR)
- `js/app.js` — محرك الموقع والنطق الصوتي (`Web Speech API`) والبحث وحفظ التقدم
- `js/data-1-4.js` — بيانات الدروس من 1 إلى 4
- `js/data-5-8.js` — بيانات الدروس من 5 إلى 8
- `js/data-9-12.js` — بيانات الدروس من 9 إلى 12
- `js/data-appendix.js` — الملحق الذهبي لامتحان A1 (الإعراب، أفعال Perfekt، قوالب Schreiben، بطاقات Sprechen)

## طريقة التشغيل المحلي (بدون إنترنت أو سيرفر)
1. فك ضغط الملف المضغوط.
2. اضغط مرتين على ملف `index.html` ليفتح مباشرة في متصفح Chrome أو Edge.

## طريقة رفع الموقع مجاناً على الإنترنت (خلال دقيقتين)

### الخيار 1: GitHub Pages
1. أنشئ Repository جديد على GitHub (مثلاً `deutsch-a1-master`).
2. ارفع جميع الملفات والمجلدات (`index.html`, `css/`, `js/`) مباشرة داخل الـ Repository.
3. ادخل إلى **Settings → Pages**.
4. تحت **Branch** اختر `main` و `/ (root)` ثم اضغط **Save**.
5. خلال دقيقة سيظهر رابط موقعك المباشر جاهزاً للمذاكرة من اللابتوب والتابلت والموبايل.

### الخيار 2: Cloudflare Pages
1. اربط حساب GitHub في لوحة Cloudflare Pages، أو اختر **Direct Upload** واسحب مجلد الموقع مباشرة.
2. لا يحتاج أي Build Command (الموقع Static بالكامل بـ HTML/CSS/JS).
